Getting started

You need Windows, OBS Studio, and Node.js 20 or newer from nodejs.org (the LTS installer is fine).

  1. Start the app. Unzip the achat folder somewhere permanent and double-click start.bat. The first run installs its packages. Keep the window open while you stream.
  2. Add the overlay. In OBS, add a Browser Source with http://127.0.0.1:7788/overlay?layer=all. Set its Width and Height to your layout canvas (1920 by 1080 unless you changed it; OBS starts new sources at 800 by 600, which makes everything small) and tick "Refresh browser when scene becomes active".
  3. Add the control panel. In OBS, open Docks, then Custom Browser Docks. Paste the dock link from the app window, the one containing token=. Treat that link like a password and keep it off stream.
  4. Connect a channel in the Connect section of the panel, then open the Test button in the bottom-right corner and run "Chat message" to see a card appear.

Connect your channels

Type your channel in the box and press Connect. Once connected, the button becomes Reconnect: change the channel name and press it to switch, or use Disconnect.

YouTube takes your @handle, channel ID or a video link. It checks every 30 seconds until you go live, and Reconnect checks right away. Members-only streams can't be read because they need a logged-in member.

Twitch takes your channel name and connects instantly, no login needed.

TikTok takes your username. TikTok has no official chat API, so it goes through a free signing service with rate limits; an Euler Stream key raises them.

Each platform runs on its own. If one has trouble, the others keep going.

Arrange the layout

Layout only affects the "Everything" Browser Source; the single-part links always fill their own source. Open the full-screen editor from the Layout section for a big canvas with a live preview of your overlay behind the boxes. It shows three boxes: Chat, GIFs and Poll. GIFs fill the GIFs box; switch on "Also show GIFs inside chat" in the GIFs section if you want them in chat too. Drag a box to move it and drag any corner or side to resize it. Snap keeps boxes on the grid, and the minus and plus buttons change the grid size.

Select a box to type exact numbers, hide it, or lock it so it can't be moved by accident. Arrow keys nudge the selected box by one grid step, or five with Shift.

Pick "1080 by 1920 vertical" if you stream to TikTok in portrait. Your "Everything" Browser Source must use the same size as the canvas.

Style and themes

In Style, choose Template or Custom CSS; only one can be on. Templates: Default (the only one whose colors you can edit), Dark, and four window templates with a mascot peeking over the corner: Kitty Window (pink, black cat), Bunny Note (lavender, white bunny), Matcha Leaf (green, frog) and Starlight (midnight blue, sleepy star). They give hosts, mods, VIPs and members/subs their own tag, and Super Chats turn the window gold. Animation settings are in Style too, and so is the look of this control panel (Light or Dark). You can also pick your own card background and border colors and set how see-through the cards are.

Edge fade makes messages melt away near the top and bottom of the chat area. Set how far each fade reaches and how strong it is.

Platform logo shows where a message came from, on the avatar's bottom-right corner or the card's top-right corner. Replace any logo with your own image.

Custom CSS is its own theme. Pick "Custom CSS" in Style and the built-in look switches off; chat is then built with the same structure as YouTube's chat page, so CSS made for YouTube live chat works for all three platforms. On the Chat only link chat then fills the whole Browser Source like YouTube's chat popout; on the Everything link it sits in the Chat box from Layout. Every other Style setting switches off, except the edge fade and chat size. Platform logos are not shown in Custom CSS mode. Paste CSS or load a .css file (up to 3 MB), press Save, and keep as many presets as you like. New to CSS? Press "Start from the starter" in the editor, and read CUSTOM-CSS-GUIDE.md in your achat folder. For example:

yt-live-chat-text-message-renderer #message { font-size: 22px; }
yt-live-chat-text-message-renderer[author-type="member"] #author-name { color: #ff6a13; }

Animation

Messages always arrive one at a time. Choose how each one enters: Slide up (the default), Speech bubble (the card puffs out of the avatar like a cloud, from a random side), Fade and slide, Cloud, Pop, or a slide from the left or right. When chat is busy, each message pauses for a readable moment; during a flood only the newest waiting messages are kept so the overlay never falls far behind.

GIFs

Switch GIFs on or off in the GIFs section, then choose where they appear: Chat (as a message that scrolls with chat) or Layout box (the GIFs box from Layout, needs the "Everything" source). Viewers type !gif happy cat. To try it yourself, open the Test button, pick "Type like a viewer" and type sample, !gif happy cat or one of your own commands.

KLIPY is the default provider. A new key allows 100 searches an hour; request a production key in the KLIPY dashboard for unlimited searches, then set the hourly limit to 0. Leave KLIPY's optional ads off; achat also drops ad results. GIPHY works too, with 100 searches an hour on a free key.

Every GIF passes a G rating, your blocked word list and cooldowns. Nothing is perfect, so "Remove last GIF" in the panel and !skipgif in chat take a GIF down everywhere at once.

Your own GIFs

In Custom GIFs, upload a GIF, PNG, WEBP or JPG (up to 8 MB) and give it a command like x03. Viewers type !x03 and it shows wherever GIFs show. Custom commands share the GIF cooldowns but never use search limits.

Polls

Start a poll from the Polls section: a question, 2 to 6 options, and a length. Choose whether it appears at the top of chat or in the Poll box from Layout. Viewers vote with each option's command, !vote1, !vote2 and so on by default; you can rename them, for example to !yes and !no. !vote 1 with a space always works too. Each viewer has one vote and can change it until the poll ends. Live bars show in the Poll box, and the winner is highlighted at the end. Your mods can start one from chat with !poll Question | Option A | Option B.

Troubleshooting

YouTube says "Not live yet"

First check that the channel is live on YouTube itself; many streamers are live only on Twitch. Press Reconnect to check right away, and look at the Log for what each check found. Pasting the stream's video link skips detection entirely.

Test GIF does nothing

The Test button's "GIF" uses a built-in sample, so it works without a key. If that shows but viewer GIFs don't, check your KLIPY or GIPHY key; the GIFs section shows the result of the last request.

Animations stutter in OBS

In OBS Settings, Advanced, turn on "Enable Browser Source Hardware Acceleration" and restart OBS. In the Browser Source properties, tick "Use custom frame rate" and set 60.

Changes don't appear

After updating the app, right-click the Browser Source and choose Refresh, and close and reopen the dock.

Safety

Chat is always shown as plain text, never as code, so a crafted message can't run anything in OBS. Viewers can't post links or images; pictures come only from the platforms' own servers, GIF providers, or files you uploaded. The app only listens on your own PC, and the panel needs your private token. Keep OBS updated too.
