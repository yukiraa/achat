    YouTube

    Official YouTube Data API (optional)

    By default achat reads chat the way youtube.com's own chat window does, with no key. If you'd rather use Google's official API, create an API key with "YouTube Data API v3" enabled at console.cloud.google.com and paste it here. A free key has 10,000 quota units a day and each chat check costs 5, so the default of one check every 8 seconds covers about 4.5 hours of streaming a day. When the quota runs out, achat switches back to the default method by itself.

    Chat look

    Pick a ready-made template, or style chat yourself with Custom CSS. Only one can be active at a time.

    Templates are unavailable while Custom CSS is on. Switch to Template above to use one again.

    Chat is built with the same structure as YouTube's chat page, so CSS made for YouTube live chat (like most VTuber chat themes) works here, for YouTube, Twitch and TikTok messages alike. Useful targets: yt-live-chat-text-message-renderer, #author-name, #message, [author-type="member"], .platform-youtube.

    New to Custom CSS? Press "Start from the starter" for a working example with notes, or read CUSTOM-CSS-GUIDE in the achat folder.

    Presets are stored on this PC. Files up to 3 MB are fine, including CSS with images built in.

    Custom CSS is unavailable while a template is on. Switch to Custom CSS above to use it.

    Custom CSS is on, so your CSS decides how chat looks: size, colors, position and animation. Only the edge fade and chat size below still apply. The other template settings are switched off. Switch to Template above to use them again.

    Edge fade

    Chat size

    Scales the whole chat, whatever the look, including Custom CSS. Use this when chat is too big or too small for its box.

    On: making the Chat box twice as wide (in Layout or Position on stream below) makes chat twice as big. Moving the box never changes the size.

    Colors

    Text switches to light automatically on dark backgrounds.

    Animation

    Messages arrive one at a time. When chat is fast, each one stays still for the reading pause.

      GIFs

      When GIFs are off, !gif, your own GIF commands and GIF tests all do nothing.

      Chat: the GIF appears as a message and scrolls with chat. Layout box: the GIF shows in the GIFs box you place in Layout (needs the "Everything" source).

      Height of GIFs shown inside chat. GIFs in the Layout box follow the size of that box.

      Viewers type !gif happy cat. Try it yourself with the Test button, bottom right.

      Search settings

      A new KLIPY key is a test key (100 searches an hour). In the KLIPY dashboard, use "Request Production" on the key for unlimited searches, then set the limit below to 0. Leave KLIPY ads off; achat also skips ad slots so none reach your stream.

      Keep this under 100 on test keys. Set it to 0 only with an unlimited production key. Repeat searches are cached and don't count.

      Your own GIFs

      Upload a GIF or image and give it a command. Viewers type the command, like !x03, and it shows wherever GIFs show. Same cooldowns as !gif, no search limit used.

        Clock

        Shows your PC's time on stream. Turn it on above, then place it below. The clock grows or shrinks to fill its box.

        Look

        "Match chat template" follows the look you picked in Style (with Custom CSS on, it uses Plain). A template picked here is only for the clock, so chat and clock can look different.

        What it shows

        Want the clock as its own OBS source instead? Use the "Clock only" link in Connect.

        Chat polls

        Viewers vote with the commands below, from any platform. One vote each; voting again changes it. !vote 1 with a space always works too.

        No poll running

        Vote commands

        Each option's command. For example !yes and !no. Use ! then letters, numbers or _, no spaces, all different.

        Settings

        Mods can type !poll Question | Option A | Option B to start one and !endpoll to close it.

        Blocked from commands

        Names here can still chat but can't use !gif, custom commands or !vote. One per line.

        Chat commands for mods

        Your channel mods and you can type !skipgif, !poll Question | A | B and !endpoll in chat.
